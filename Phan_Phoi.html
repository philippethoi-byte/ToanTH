Lý thuyết Phép Phân Phối

➕ Nhân với một TỔNG

a × (b + c) = a × b + a × c

Nhân số đó với từng số hạng của tổng rồi cộng lại.

Ví dụ: 5 × (10 + 2) = 5×10 + 5×2 = 60

➖ Nhân với một HIỆU

a × (b - c) = a × b - a × c

Nhân số đó với số bị trừ và số trừ rồi trừ kết quả.

Ví dụ: 5 × (10 - 2) = 5×10 - 5×2 = 40

➕ Chia một TỔNG

(a + b) : c = a : c + b : c

Chia từng số hạng của tổng cho số chia rồi cộng lại.

Ví dụ: (80 + 20) : 5 = 80:5 + 20:5 = 20

➖ Chia một HIỆU

(a - b) : c = a : c - b : c

Chia số bị trừ và số trừ cho số chia rồi trừ kết quả.

Ví dụ: (100 - 20) : 4 = 100:4 - 20:4 = 20

🔄 Phép Thuật "Gom Lại" (Ngược lại)

Gom thừa số chung:

a×b + a×c = a × (b + c)

Gom cùng số chia:

a:c + b:c = (a + b) : c
